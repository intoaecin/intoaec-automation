Framework observations

Framework: Cucumber.js + Playwright with Gherkin features, step definitions and page objects. The project contains 138 feature files, 156 page-object files and 145 step-definition files.
  • 376 scenario declarations were parsed; 375 are meaningful after excluding the explicit placeholder.
  • 58 feature files have no scenario declaration.
  • Approximately 1,910 getByRole, 156 getByLabel and 339 waitForTimeout references were found.
  • playwright.config.js defines 60-second test, 15-second action and 30-second navigation timeouts with zero retries; browser projects are not declared.

Runtime pass/fail is not represented because local automation dependencies were not installed during the static assessment.

Recommendations

  1. Install locked dependencies and run a local Cucumber dry-run baseline.
  2. Automate recovery, signup and customer/client portals.
  3. Prioritize invoices, bills/expenses, credit notes and subscription payments.
  4. Complete inventory, goods receipt, worker, asset, BOQ and progress-claim workflows.
  5. Replace hard waits with condition-based waits and add explicit browser projects and CI artifacts.
